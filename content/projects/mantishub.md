MantisHub is a hosted issue tracker and helpdesk built on the open source Mantis Bug Tracker. Teams use it to track bugs and tasks, run a helpdesk by email, and keep a project wiki.

I've worked on MantisHub since December 2024, across the PHP core, the plugins and the desktop app.

---

### What I built

- New features and fixes in the PHP core and plugins: the Modern UI, project-specific settings, account security and email notifications
- Helpdesk safeguards for incoming email, and batched email lookups for faster notes
- The ApiX REST API used by the web and desktop apps
- Wiki pages with labelled and cross-project links, and recurring tasks created from existing tasks
- The Electron desktop app, built with Vite, TypeScript and Tailwind CSS
- PHPUnit test coverage for settings, permissions and the API, run in GitHub Actions
